DOODLE COVERT v0.1 — original 4th Heaven doodles

GODOT: Open godot-project/project.godot in Godot 4.3 and press Play.
BROWSER: Host the entire web folder on an HTTPS static host. For a desktop test,
run python3 -m http.server 8080 --directory web, then open http://localhost:8080.
Opening index.html directly as a local file will not work.

Move with WASD/arrows or the left touch joystick. Hold Shift/Space or RUN
to run. Collect three intel cases and reach the southeast extraction circle.
Walls block sight; green zones hide you while walking. Running makes noise.
Yellow cones show guard vision. Escape a chase by breaking sight and hiding.
Next Sector and Retry happen in-game without reloading the page.

This includes a single-threaded DEBUG web test build (larger than release).
Source gameplay tests and exported-pack startup checks passed. Browser visuals
and Telegram mobile performance have not yet been checked on a real device.
No live Telegram bot or leaderboard is connected. Best score is session-only.

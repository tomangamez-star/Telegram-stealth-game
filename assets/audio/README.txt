DOODLE COVERT OPTIONAL SOUND FILES

Place your sounds in this folder using exactly one of these extensions:
.wav (preferred for short effects) or .mp3

Exact filenames:
player_stealth_steps.wav
player_run_steps.wav
guard_steps.wav
guard_cough.wav
guard_notice_shout.wav
guard_suspicious.wav
intel_collect.wav
mission_complete.wav
mission_failed.wav

You may use .mp3 instead, for example: guard_cough.mp3
Do not add both WAV and MP3 versions of the same sound.

After adding sounds, rebuild the web export so Godot packs them into docs/index.pck.
The game runs normally when any or all sounds are missing.
